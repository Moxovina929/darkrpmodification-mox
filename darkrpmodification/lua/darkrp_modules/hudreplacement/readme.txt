Это пример аддона, который позволяет заменить HUD целиком или только его части.
В нём есть код ОЧЕНЬ простого HUD — он только показывает, как это работает.

Зато в нём есть код, который скрывает части стандартного HUD DarkRP.
Это может пригодиться, если у вас есть свой HUD, который вы хотите подключить.
