# darkrpmodification-mox
Готовая базовая конфигурация darkrpmodification для серии видео по созданию DarkRP-сервера на моем канале Mox.
Оригинал сборки https://github.com/FPtje/darkrpmodification

# Что изменено:
1. Первичная настройка режима.
2. Полный перевод комментариев к коду.
3. Локализация режима на русский язык.
4. Отключение kill команды в консоли darkrp_modules\disablekill.
5. Отключение пищащего звук при возрождении из sandbox darkrp_modules\nodeathsound.
